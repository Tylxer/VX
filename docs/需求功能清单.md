包名：`com.tencent.mm` · 模块包名暂定 `com.lx.wxgroup`

## 一、产品形态（已锁定）

会话列表里，分组行就是**列表中的普通一行**：与会话行等高、跟列表一起上下滚动、会被滑走。
点击分组行 → 右滑进入二级分组页，二级页复用微信会话行的渲染，只是数据源换成该分组成员。

## 九、开工前必须落实的技术前提

反编译微信 8.0.48 APK 后需确认以下类名（决定 F2 与全部 hook 可行性）：

1. 会话列表 Adapter 类（及 `getCount` / `getView` / `getItem` / `getItemViewType`）
2. 会话 item 的 layout 资源名（二级页要复用同一渲染）
3. 会话列表点击回调（onItemClick）与长按菜单入口
4. 会话对象的 username / 昵称 / 摘要 / 时间 / 未读数字段，以及**头像加载接口**（A4-a 需要）
5. 置顶会话的判定字段（用于 A13 定位置顶区边界）
6. 微信原生「标签 → 添加成员」选择界面的类名与其「确定」回调（D3/D4）
7. 标记已读 / 删除会话 / 置顶会话 的调用入口（B7、A7）
8. **右上角「+」下拉菜单的实现类与菜单数据源**（G1，需确认是 `MMListPopupWindow` 还是自定义 PopupWindow）
9. **撤回消息的处理入口**（防撤回功能域）
10. **朋友圈数据接口**：动态拉取与刷新、动态/评论的删除标记（防撤回 + 朋友圈域都要）
11. **红包领取界面（拆红包页）的「拆红包 / 领取」按钮**（红包域：不 hook 消息接收，只在领取界面出现后自动点击该按钮）
12. **双击头像触发拍一拍的手势处理入口**（聊天域 · 禁用双击拍一拍）
13. **消息列表渲染入口**：防撤回需要在撤回提示消息的生命周期里替换内容；且「显示撤回提示」关闭时，要能在渲染阶段过滤掉**历史已存在**的撤回提示消息（不只是拦新的）
14. **被 @ 时的响铃与震动入口**（聊天域 · 防止被@）：只需拦住「收到 @ 我的消息 → 播放提示音 / 触发震动」这一个点。
    **不要动**角标、消息渲染、通知栏 —— 「[有人@我]」标记与消息本体必须保持微信原样。
    需要能识别「这条消息 @ 了我」以及「来自哪个群」（用于查允许/排除名单）

获取方式：手机连 USB 授权调试后 `adb shell pm path com.tencent.mm` 拉取 APK 反编译。
