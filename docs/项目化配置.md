# wxgroup 模块开发 · WorkBuddy「项目」化配置

> 用途：把本模块的长期开发从「反复新建空间」改成「一个项目 + 稳定本地空间」。
> 本文件三块内容分别用于：① 粘贴进 WorkBuddy 项目→指令栏；② 放进项目资产库；③ 整理本地空间。
> 项目是**云端配置层**（指令/资产/专家），源码仍留**本地空间 + git**，不进云端。

---

## ① 项目指令（复制粘贴到 项目 → 指令）

```
# 微信好友分组 LSPosed 模块（com.lx.wxgroup）开发项目

## 一、模块目标
为微信 8.0.48（谷歌 Play 版）开发好友/群分组 Xposed 模块，注入会话列表分组行、
群发、防撤回、红包、朋友圈、备份等能力。宿主包 com.tencent.mm，模块包 com.lx.wxgroup。

## 二、技术栈与构建
- 目标环境：微信 8.0.48 GP · LSPosed 2.0.1 (7639) · JDK 21 + SDK 34（本机无 JDK17/NDK）
- 构建：compileSdk 35 / buildTools 35.0.0 / minSdk 26 / targetSdk 33 / jvmTarget 17
- 工程：单 Gradle 工程 WXGroup，仅 :app 模块；代码在
  wxgroup/app/src/main/java/com/lx/wxgroup/{core,feature,ui,data,probe,hook}
- 构建用 assembleDebug（勿跑 build）；循环调试 python tools/dev.py loop|q|ui|restart

## 三、模型路由（强制）
- PRO 档 = 裸写 `deepseek-v4-pro`（workbuddy 内置 Deepseek-V4-Pro）
- FLASH 档 = 裸写 `deepseek-v4.1-flash`（workbuddy 内置 Deepseek-V4.1-Flash）
- 判据设计/根因推理/Hook链路/复核异步·并发 等 Pro 类任务 → 单开子代理派发 PRO 档

## 四、协作纪律（硬规则，违反即止）
1. 正式开发等用户通知，不自行开工/调设备；收尾即停。
2. 真机测试前必须交叉验证代码变更（diff 交第二视角复核）再装包。
3. 派发不阻塞：派完子代理立刻在同一轮继续做实事。
4. 提及群聊/好友一律用昵称（有 conRemark 用备注），不许只报 wxid。
5. 锚点用 K-前缀（K1弹窗/K3选择器/K7 Adapter包装/K9静音判定…），结论存 docs/conclusions/，操作手法存 docs/开发回路速查.md。
6. 缓存集合必须挂版本号；拦 SQL ≠ 拦住删除（撤回语音仍走 File.delete）；朋友圈防撤回=写时拦截（updateWithOnConflict before 移除 sourceType）。

## 五、判据纪律（连续栽过的坑）
- 对着用户能看见的事实写，别对着内部计数器（bound 是绑定过的 View 集合，与开关无关）。
- 互斥判据别写成并列（如 VFG blocked 与 VB restore ok 互斥，总判=1或3）。
- 三条结论来源纪律：dex 有 SQL 字符串 ≠ 该业务调用它；「A推B」时序须标假设；单测必须做变异验证。
- 子代理自报模型名是陷阱，看其落盘产物与 transcript 的 requestModelId 判实际档位。

## 六、本机环境要点
- JDK 21：G:\Program Files\Microsoft\jdk-21.0.7.6-hotspot；SDK：C:\Users\lx\AppData\Local\Android\Sdk
- 无 NDK/cmake/cmdline-tools/Android Studio；Gradle 不在 PATH，需自下载分发包
- 子代理连「输出」都不可靠：要产出就让它写文件/改代码，别指望回复带结论
```

## ③ 本地空间目录规范（稳定命名，不再每轮新建时间戳空间）

```
wxgroup-dev/                        ← 固定命名的本地空间（替代 2026-09-29-20-23-21）
├── wxgroup/                        ← git 仓库根（WXGroup 工程，唯一真源）
│   ├── settings.gradle.kts         ← rootProject.name="WXGroup", include(":app")
│   └── app/src/main/java/com/lx/wxgroup/...
└── docs/                           ← 模块文档（与代码同空间，便于引用）
    ├── 需求功能清单.md
    ├── 取证结论.md
    ├── conclusions/
    ├── 并行编排routine.md
    ├── 项目化配置.md               ← 本文件
    └── _archive/                   ← 已完成轮次残渣（_r*.md / 截图 / db）归此处，勿堆根目录
```

执行要点：
- **一个稳定空间管到底**，不再用时间戳空间；新开发轮次 = 在项目里开「本地任务」指向该空间。
- 分析残渣（`_A0.png`/`_ab.db`/`_acc.sh`/`_anr*.txt`/`_r*.md` 等）移入 `docs/_archive/`，根目录只留 `wxgroup/` 与 `docs/`。
- git 远端已配 post-commit 自动 push，提交后用 `git status` 确认 .workbuddy 不被误提交（gitignore）。
