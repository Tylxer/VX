### 2.2 「模块转发必模糊 → 必须改码修复」前提裁决

- **作为全称命题：不成立【真机实证·高】**。用户肉眼 + arm 铁证 + 当前码未写 fullpath 三者合起来，构成一个明确的「模块转发且清晰」反例。「必模糊」被证伪。
- **作为存在性事实：仍成立【真机实证·高】**。历史 B 态（02:12）模块转发模糊 = 9554B/`0ef205c1` 是实测双证，不能因一次反例抹掉。失败模式真实存在，修复目标不消失。
- **根因重估**：既然当前码不写 fullpath 也能清晰，则「模糊」的成因更可能是**同一张 216b 图在不同时刻的本地 hevc 缓存形态**（原图 45522B vs 压缩 9554B；见 1.4 复核），而非「我方代码没写 fullpath」这一单一因素，也**不是换了张图**。P-FS 热修只在「原图在本地但原生链没喂进去」这一子情形下才有价值。

### 2.2b team-lead 追问「若图不同，对历史那张图是否仍需修复」的处置

- **字面前提不成立**：1.4 已【真机实证·高】证本次与历史 A/B 是**同一张 216b 坏图**，故「换了一张图、历史那张仍模糊仍须修」这一字面分叉**不适用**。
- **但其关切的内核仍然成立，且已被吸收进本裁决**：真正变化的不是图片身份，而是**本地 hevc 缓存状态**。216b 在 R74~R79 era「本地无大图、仅 36B + 15KB 缩略图」（`_r76:45`/`_r77:12`），22:01 时本地已有 `cff4f5a5`/45522B 原图 hevc。⇒ 对**历史 B 态那个缓存状态**（只有 9554B 压缩 hevc），模块转发仍会模糊、仍可能是修复目标——这一点与「图不同」无关，已写入 2.4 行 2「状态依赖 ⇒ 热修对子情形仍必要」。
- **对路线的净影响**：换图候选被排除**并不放松**「先复现再决定」的推荐，反而使其更聚焦——Q3 的复现必须**固定同一张 216b 图**，把**源记录 / 本地缓存状态**作为唯一变量（步 2 换记录是关键），而不是去重测一张新图。若复现证实「同一 216b 图、缓存有原图时模块转发稳定清晰；缓存只有压缩 hevc 时稳定模糊」，则①②的 NO-GO 维持与补基线结论坐实，热修按 2.4 行 2 有条件保留。

### 2.3 为什么推荐「先复现再决定」而非「仍按改判落码」

1. **前提已倒**：落码的唯一驱动力（必模糊）被真机反例证伪；在不成立的前提上落码，等于把未证必要性当成已证。
2. **单次样本不足以定性**：一次清晰既可能是稳定机制，也可能是状态依赖 / 偶发（Q1 Q4 均标 UNKNOWN）。落码决策不应押在单样本上。
3. **收益/风险比未证**：修复是写宿主 task 字段的侵入性变更（`field_fullpath`）；在「现状已能清晰」时落码，净增回归面与写入面，而收益未经稳定基线证明。
4. **复现成本极低**：Q3 的方案**不开闸、不改码、不落码**，仅几组肉眼 A/B + 可选只读探针即可定性。先复现几乎零成本。
5. **判据会失去区分力**：若现在落码，验收判据「A→B→A 翻清晰」在当前 B 已清晰的前提下无法验证「翻清晰」，只能验证「仍清晰」——恰恰说明应先拿到稳定基线。
6. **泛化硬伤**：postprobe 自标 `45522L`/`cff4f5a5` 是本图热修常量、换图必失效【UNKNOWN】。即便落码也只对本验证图有效，不应作为通用修复宣称。

### 3.3 开 SCD 主探针看出口 md5 的开法与风险

- **开法**（广播到 `com.lx.wxgroup.action.PROBE`）：

  - 关：`... --es op stockcdn --es sub off`

- **风险与纪律**：
  1. **日志易丢**：出口 md5 依赖 logcat 环形缓冲，22:01 已被刷掉一次 ⇒ **必须先做步 0 落盘**，否则重蹈覆辙。
  2. **纯只读、不写 host**：SCD 各 guard 只读 `param.args`/字段，不写 task、不调宿主业务方法、不发消息；与写闸门完全隔离。
  3. **常驻 hook 开销**：开启期间 11 个 hook 常驻打日志，有轻微性能/日志量开销；取证后**必须 off**，避免本进程持续打日志（冷启才复位，`EntryReceiver.kt:274` 明示）。
  4. **可达性边界**：若某轮 `SCD-x0cb` 未打点（回调未触发 / inject 闸门未开），则「出口 md5」仍是【UNKNOWN】，**不得以 P-FS `hit=1` 越级推出出口 md5=cff4f5a5**。
  5. **不作终审**：出口 md5 只是机制旁证（证明字节写对），唯一 go 坐实仍是对端肉眼 + A→B→A 翻转。
