## R31（分组置顶 + 折叠置顶聊天）

用户需求原文：
1. 分组置顶不需要在右边显示「置顶」两字。
2. 分组置顶跟常规置顶一样，也能被「折叠置顶聊天」收入。

真机反馈（用户确认）：「折叠置顶聊天时，分组行**停在最上面，没跟着收起**」。

### 现状事实（已核）

- ⚠️ **方向订正**：默认 `chat.group_row_enabled = "true"` ⇒ `GroupBar` 走 `MODE_NONE`，**不注入任何 UI**（`GroupBar.kt:385-403`）。用户看到的分组行是 `ConvFilter.GroupedAdapter` 在 adapter 内插入的行 ⇒ `GroupBar.syncPinFold()` / `applyFold()` / `FOLDED_H` 那一整套**对默认用户是死代码**，最初「height 被撑回」的假设已作废。
- 真正的硬插在 `data/ConvLayout.kt:119`：`for (g in pinned) rows.add(ConvRow.Group(g.id))` —— 置顶分组行无条件排最前，与微信置顶区没有任何联动。折叠置顶聊天时 `convs` 里的置顶会话被收走，这一行照样存在 ⇒ 「停在最上面」。
- 文案已排除：`aapt2 dump strings _cache/base.apk` 实查 8.0.48 有 `%d个置顶聊天`(#20938) 与 `折叠置顶聊天`(#20939)，与旧判据一字不差。
