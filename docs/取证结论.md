## 三条「结论来源」纪律（与 `CLAUDE.md` 一致）

- **dex 里有 SQL 字符串 ≠ 该业务调用它** ⇒ 形态必须反汇编到 `invoke-*` + 调用者链才成立。
- **「由 A 推 B」的时序结论必须标假设**；时序只认 **`invoke` 地址单调递增** / **真机日志时间戳**。
- **单测必须做变异验证**：改坏被测逻辑后必须看到对应用例变红（且最好只有它红），否则是假绿。
